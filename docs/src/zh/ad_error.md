# 当显示“违反使用条款”时

本页面提供在浏览网站时出现以下错误消息的处理方法。

> **显示的消息示例**
> 违反使用条款
> 在您的浏览器中检测到广告拦截器。
> 使用Search3958网站即视为您同意使用条款。
> 为避免许多问题，请允许广告或撤回您对使用条款的同意。

---

## 解决方法

### 1. 如果您正在使用广告拦截器（扩展程序）

要使用该网站，您需要禁用广告拦截器或将此网站添加到例外列表。

* **更改设置的方法**
* 在浏览器的扩展程序设置中，将此网站（Search3958）注册到“允许列表”或“例外列表”中。
* 如果要删除扩展程序，请从Chrome Web Store等位置卸载它。
* 您也可以从错误屏幕上的“允许广告”按钮访问Chrome Web Store。



---

### 2. 如果您未使用广告拦截器 / 即使关闭也无法解决问题

您浏览器的隐私和安全功能或跟踪预防功能可能会影响网站。

* **检查浏览器安全和隐私设置**
* **如果您使用的是Microsoft Edge**
> 在“隐私、搜索和服务”设置菜单中将跟踪预防强度从“严格”更改为“基本”或“平衡”，可能会解决此问题。
* **如果您使用的是其他浏览器（Chrome / Safari / Firefox等）**
> 同样，过度的跟踪预防功能或对第三方Cookie的限制可能是原因。请暂时放宽安全级别再试一下。



* **如果显示“您已撤回同意”的屏幕**
> 点击屏幕上的“同意使用条款”返回原始页面。

---

## 运营方请求

本网站通过显示的广告收入来维持和改进服务。

因此，使用广告拦截器构成对本网站使用条款的违反。为了服务的可持续运营，我们恳请您理解并配合禁用广告拦截器，并允许在本网站上显示广告。
