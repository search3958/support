# Newtab 设置方法

本页面提供如何将Newtab（[https://search3958.github.io/i/newtab/](https://search3958.github.io/i/newtab/?utm_source=gemini)）设置为浏览器打开新标签页时显示的页面的说明。

设置通过3个步骤完成

---

## 设置步骤（适用于Chrome系列浏览器）

### **步骤1：安装扩展程序**

要将Newtab加载为新标签页，请安装专用的扩展程序。

从Chrome网上应用店安装 **“New Tab Redirect”** 扩展程序。

### **步骤2：输入URL**

1. 安装完成后，点击浏览器右上角的扩展程序（拼图图标等）中的 **New Tab Redirect** 图标。
2. 从显示的菜单中选择 **“Set Options”**。

### **步骤3：保存设置**

1. 当选项页面打开时，在文本框中输入以下URL。
```
https://search3958.github.io/newtab/

```


2. 点击 **“Save”** 即可完成设置！

---

现在，每次打开新标签页时都会显示Newtab。
