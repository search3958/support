# SaeTab for Chrome インストール手順

## 1. SaeTabをダウンロードする

以下のリンクからZIPファイルをダウンロードします。

[**SaeTab for Chrome をダウンロード**](https://github.com/search3958/newtab/raw/refs/heads/main/saetab-for-chrome.zip)

## 2. ZIPファイルを展開する

ダウンロードした `saetab-for-chrome.zip` を右クリックし、**「すべて展開」**などを選択して解凍します。

展開したフォルダの中に、`background.js` などのファイルがあることを確認してください。

## 3. Chromeの拡張機能ページを開く

Chromeのアドレスバーに以下を入力して、拡張機能の管理画面を開きます。
このとき、右上のスイッチから`デベロッパーモード`を**必ず有効に**してください。

`chrome://extensions/`

## 4. 拡張機能を読み込む

画面右上などにある **「パッケージ化されていない拡張機能を読み込む」** をクリックします。

ファイル選択画面が表示されたら、先ほどZIPを展開したフォルダを選択してください。

**`background.js` などが直接入っているフォルダを選択するのがポイントです。**

## 5. 完了

拡張機能の一覧に **SaeTab** が表示されれば、インストール完了です。

これでSaeTabを使用できます。
