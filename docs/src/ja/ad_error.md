# 「利用規約に違反しています」と表示される場合

サイトの閲覧中に以下のエラーメッセージが表示された場合の対処方法をご案内します。

> **表示されるメッセージの例**
> 利用規約に違反しています
> お客様のブラウザで広告ブロッカーが確認されました。
> Search3958のサイトをご利用いただく場合、利用規約に同意したものとみなします。
> 多くの問題を避けるためには広告を許可するか、利用規約への同意を撤回してください。

---

## 対処方法

### 1. 広告ブロッカー（拡張機能）を使用している場合

サイトをご利用いただくには、広告ブロッカーの無効化または本サイトの除外設定が必要です。

* **設定の変更方法**
* ブラウザの拡張機能設定から、当サイト（Search3958）を「ブロックの対象外（除外リスト）」に登録してください。
* 拡張機能を削除する場合は、Chrome Web Store等からアンインストールを行ってください。
* エラー画面上の「広告を許可」ボタンからも Chrome Web Store へアクセスできます。



---

### 2. 広告ブロッカーを使用していない／オフにしても解消されない場合

ブラウザのプライバシーセーフティ機能やトラッキング防止機能が影響している可能性があります。

* **ブラウザのセキュリティ・プライバシー設定の確認**
* **Microsoft Edge をお使いの場合**
設定メニューの「プライバシー、検索、サービス」内にある**トラッキング防止**の強度を「厳重」から「基本」または「バランス」に変更することで解決する場合があります。
* **その他のブラウザ（Chrome / Safari / Firefox など）をお使いの場合**
同様に、過度なトラッキング防止機能やサードパーティ製Cookieの制限が原因となることがあります。一時的にセキュリティレベルを緩和してお試しください。


* **「同意を撤回しています」という画面が表示された場合**
画面内の「利用規約に同意する」をクリックして元の画面へお戻りください。

## 運営からのお願い

当サイトは、表示される広告収入によってサービスの維持および改善を行っております。

そのため、広告ブロッカーのご利用は本サイトの利用規約違反となります。持続的なサービス運営のため、広告ブロッカーの解除および当サイトでの広告表示にご理解とご協力をよろしくお願いいたします。
