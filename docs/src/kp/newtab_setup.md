# Newtab 설정방법

Newtab([https://search3958.github.io/i/newtab/](https://search3958.github.io/i/newtab/))을 브라우저의 새 탭을 열 때의 페지로 설정하는 순서를 안출해드립니다.

설정은 3단계로 완결됩니다.

---

## 설정순서(Chrome 계렬 브라우저의 경우)

### **1단계: 확장프로그람 안설치(설치)**

Newtab을 새 탭으로 로드하기 위해 전용 확장프로그람을 안설치(설치)합니다.

Chrome 웹 스토어에서 **"New Tab Redirect"** 확장프로그람을 안설치하십시오.

### **2단계: URL 입력**

1. 안설치가 완결되면 브라우저 우상단의 확장프로그람(퍼즐조각 아이콘 등)에서 **New Tab Redirect** 아이콘을 누릅니다.
2. 가리키는 메뉴에서 "Set Options"를 선택합니다.

### **3단계: 설정보관**

1. 옵션페지가 열리면 텍스트입력칸에 다음의 URL을 입력합니다.

```
https://search3958.github.io/newtab/

```

2. "Save"를 누르면 설정이 완결됩니다!

---

이제 새 탭을 열 때마다 Newtab이 가리켜집니다.
