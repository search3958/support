# 當顯示「違反使用條款」時

本頁面提供在瀏覽網站時出現以下錯誤訊息的處理方法。

> **顯示的訊息示例**
> 違反使用條款
> 在您的瀏覽器中偵測到廣告攔截器。
> 使用Search3958網站即視為您同意使用條款。
> 為避免許多問題，請允許廣告或撤回您對使用條款的同意。

---

## 解決方法

### 1. 如果您正在使用廣告攔截器（擴充程式）

要使用該網站，您需要停用廣告攔截器或將此網站加入例外清單。

* **變更設定的方法**
* 在瀏覽器的擴充程式設定中，將此網站（Search3958）註冊到「允許清單」或「例外清單」中。
* 如果要刪除擴充程式，請從Chrome Web Store等位置卸載它。
* 您也可以從錯誤畫面上的「允許廣告」按鈕存取Chrome Web Store。



---

### 2. 如果您未使用廣告攔截器 / 即使關閉也無法解決問題

您瀏覽器的隱私和安全功能或追蹤預防功能可能會影響網站。

* **檢查瀏覽器安全和隱私設定**
* **如果您使用的是Microsoft Edge**
> 在「隱私、搜尋和服務」設定選單中將追蹤預防強度從「嚴格」更改為「基本」或「平衡」，可能會解決此問題。
* **如果您使用的是其他瀏覽器（Chrome / Safari / Firefox等）**
> 同樣地，過度的追蹤預防功能或對第三方Cookie的限制可能是原因。請暫時放寬安全級別再試試看。



* **如果顯示「您已撤回同意」的畫面**
> 點擊畫面上的「同意使用條款」返回原始畫面。

---

## 營運方請求

本網站透過顯示的廣告收入來維持及改進服務。

因此，使用廣告攔截器構成對本網站使用條款的違反。為了服務的可持續營運，我們恳請您理解並配合停用廣告攔截器，並允許在本網站上顯示廣告。
