# Newtab 設定方法

本頁面提供如何將Newtab（[https://search3958.github.io/i/newtab/](https://search3958.github.io/i/newtab/?utm_source=gemini)）設定為瀏覽器開啟新標籤頁時顯示的頁面的說明。

設定透過3個步驟完成

---

## 設定步驟（適用於Chrome系列瀏覽器）

### **步驟1：安裝擴充程式**

要將Newtab載入為新標籤頁，請安裝專用的擴充程式。

從Chrome網上應用店安裝 **「New Tab Redirect」** 擴充程式。

### **步驟2：輸入URL**

1. 安裝完成後，點擊瀏覽器右上角的擴充程式（拼圖圖示等）中的 **New Tab Redirect** 圖示。
2. 從顯示的選單中選擇 **「Set Options」**。

### **步驟3：儲存設定**

1. 當選項頁面開啟時，在文字框中輸入以下URL。
```
https://search3958.github.io/newtab/

```


2. 點擊 **「Save」** 即可完成設定！

---

現在，每次開啟新標籤頁時都會顯示Newtab。
