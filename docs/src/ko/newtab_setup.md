# Newtab 설정 방법

Newtab([https://search3958.github.io/i/newtab/](https://search3958.github.io/i/newtab/?utm_source=gemini))를 브라우저의 새 탭을 열 때의 페이지로 설정하는 절차를 안내합니다.

설정은 3단계로 완료됩니다

---

## 설정 절차(Chrome 계열 브라우저의 경우)

### **1단계: 확장 프로그램 설치**

Newtab을 새 탭으로 로드하기 위해 전용 확장 프로그램을 설치합니다.

Chrome 웹 스토어에서 **"New Tab Redirect"** 확장 프로그램을 설치하십시오.

### **2단계: URL 입력**

1. 설치가 완료되면 브라우저 오른쪽 상단의 확장 프로그램(퍼즐 조각 아이콘 등)에서 **New Tab Redirect** 아이콘을 클릭합니다.
2. 표시되는 메뉴에서 **"Set Options"**를 선택합니다.

### **3단계: 설정 저장**

1. 옵션 페이지가 열리면 텍스트 상자에 다음 URL을 입력합니다.
```
https://search3958.github.io/newtab/

```


2. **"Save"**를 클릭하면 설정이 완료됩니다!

---

이제 새 탭을 열 때마다 Newtab이 표시됩니다.
