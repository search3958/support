# クライアント開発サービス使用方法

## 1. 導入

`client-service.js` を配信するページに読み込みます。

```html
<script src="https://search3958.github.io/frameworks/client-service.js"></script>
```

読み込み後、グローバルオブジェクト `window.OF8Account` が利用できます。

```js
console.log(window.OF8Account.constants.apiBase);
```

> ファイル名は `client-service.js` である必要があります。ソースコード冒頭のコメントにもある通り、デプロイ時にこの名前に変更してください。

## 2. 最小構成の例

```html
<!doctype html>
<html lang="ja">
<head>
  <meta charset="utf-8">
  <title>サンプル</title>
</head>
<body>
  <button id="login">ログイン</button>
  <button id="save">保存</button>
  <p id="out"></p>

  <script src="./client-service.js"></script>
  <script>
    const OF8 = window.OF8Account;

    document.getElementById("login").addEventListener("click", async () => {
      try {
        const result = await OF8.login();
        document.getElementById("out").textContent = `ようこそ ${result.account.name} さん`;
      } catch (error) {
        alert(error.message);
      }
    });

    document.getElementById("save").addEventListener("click", async () => {
      try {
        await OF8.setItem("memo", "こんにちは");
        const value = await OF8.getItem("memo");
        document.getElementById("out").textContent = `保存値: ${value}`;
      } catch (error) {
        alert(error.message);
      }
    });
  </script>
</body>
</html>
```

## 3. 基本的な流れ

1. **ログイン** — `OF8.login()` をユーザー操作の中で呼ぶ。ポップアップでログインが完了すると、Cookieとデータアクセスキーが保存される。
2. **データ操作** — `getItem` / `setItem` / `removeItem` などを呼ぶ。内部で必ずサーバーと同期する。
3. **ログアウト** — `OF8.logout()` でトークンを失効させ、ローカルの情報を削除する。

## 4. ログイン状態の確認

ページ読み込み時に、ログイン済みかどうかを判定できます。

```js
const loggedIn = await OF8.isLoggedIn();
if (!loggedIn) {
  // ログインボタンを表示する
}
```

`isLoggedIn()` はCookieが無い場合はネットワーク通信せず `false` を返します。Cookieがある場合はサーバーに問い合わせて有効性を確認します。

## 5. よくある組み込みパターン

### ログイン後に既存データを読み込む

```js
async function initApp() {
  if (!(await OF8.isLoggedIn())) return;
  const settings = await OF8.getItem("settings");
  applySettings(settings ? JSON.parse(settings) : {});
}
```

### 値をJSONとして保存する

値は必ず文字列です。オブジェクトは `JSON.stringify` して保存してください。

```js
await OF8.setItem("settings", JSON.stringify({ theme: "dark", fontSize: 16 }));
```

### 読み込み時の待ち時間を減らす

`getItem` は毎回サーバーにアクセスします。頻繁に読む値は、起動時に一度 `sync()` して結果を使い回すか、`readCache()` を使ってください（詳しくは「詳しいデータの扱い方」を参照）。

## 6. 開発時の注意

- **ユーザー操作の中で `login()` を呼ぶこと。** ポップアップブロックの対象になります。
- **HTTPSで配信すること。** 開発時は `localhost` を使ってください。
- **オリジンごとに別アカウント扱いではないこと。** アカウントは共通ですが、データはオリジンごとに分かれます。
- **ログアウト後はデータ操作が失敗すること。** 再ログインしてください。
- **ファイル名・配信パス。** ログイン画面のURLは `https://search3958.github.io/support/accounts/account-login.html` に固定されています。

## 7. 開発用の動作確認チェックリスト

- [ ] `window.OF8Account` が存在する
- [ ] ログインボタンでポップアップが開く
- [ ] ログイン後に `isLoggedIn()` が `true` を返す
- [ ] `setItem` → `getItem` で同じ値が返る
- [ ] `logout()` 後に `isLoggedIn()` が `false` を返す
