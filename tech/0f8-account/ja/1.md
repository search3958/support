# 0F8アカウントサービスができること

## 概要

0F8 アカウントサービスは、複数のWebアプリ（オリジン）から共通のアカウントを使い、ユーザーごとのデータを安全に保存・読み出しするための仕組みです。

開発者は `client-service.js` を読み込むだけで、次の機能を利用できます。

- ユーザーのログイン／ログアウト（別ウィンドウのログイン画面を利用）
- オリジン（ドメイン）ごとの文字列データの保存・取得・削除
- アカウント情報（表示名、アイコン）の取得
- 保存容量の確認
- ログイン状態の確認

## 主な特徴

| 項目 | 内容 |
|---|---|
| データの分離 | 保存データはオリジン単位で分かれます。あるアプリのデータを別のアプリから読むことはできません。 |
| 暗号化 | データはサーバーに届く前にクライアント側の鍵で暗号化された状態で保存されます（AES-GCM）。 |
| トークン管理 | アクセストークンは3日間有効で、残り1日を切ると自動で更新されます。 |
| 同時ログイン制限 | アカウントあたり最大100トークンまで保持されます。 |
| ログイン保護 | ログイン失敗後は同一IPから3秒間は再試行できません。 |

## 利用できないこと（現在の公開APIの範囲外）

次の操作は、0F8の管理オリジン（`https://search3958.github.io`）からのみ許可されており、一般の開発者向けクライアントAPIには含まれていません。

- 新規アカウント登録（ログイン画面側で行います）
- 表示名・アイコンの変更
- パスワード変更
- アカウント削除
- 全端末からのログアウト
- 特定オリジンのデータ削除（管理用）

また、次のようなことはできません。

- 他のユーザーのデータを読む、またはアカウントを列挙する
- アプリ間でデータを直接共有する（共有が必要な場合は設計を別途検討してください）
- 大容量のファイル（画像、動画など）を保存する

## 対応環境

- ブラウザ: `localStorage`、`sessionStorage`、`Cookie`、`window.open`、`postMessage` が使えるモダンブラウザ
- 配信オリジン: HTTPS、または開発用の `localhost` / `127.0.0.1`
- ブラウザがポップアップをブロックしている場合、ログインはできません。ユーザー操作（クリックなど）の中で `login()` を呼び出してください。
