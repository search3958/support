# すべてのクライアントAPI

`window.OF8Account` が公開しているすべてのメソッドと定数の仕様です。

すべての非同期メソッドは `Promise` を返します。エラーは `Error` オブジェクトとして `reject` されます（`error.message` に日本語または英語の説明が入ります）。

## 一覧

| メソッド | 戻り値 | 通信 | 概要 |
|---|---|---|---|
| `login()` | `Promise<{accessToken, signature, account}>` | ポップアップ | ログインする |
| `logout()` | `Promise<void>` | POST（任意） | ログアウトする |
| `isLoggedIn()` | `Promise<boolean>` | POST（Cookieがある場合） | ログイン状態を確認する |
| `getItem(key)` | `Promise<string \| null>` | GET | 値を取得する |
| `setItem(key, value)` | `Promise<object>` | GET + PUT | 値を保存する |
| `removeItem(key)` | `Promise<void>` | GET + PUT | 値を削除する |
| `keys()` | `Promise<string[]>` | GET | キー一覧を取得する |
| `length()` | `Promise<number>` | GET | キーの数を取得する |
| `key(index)` | `Promise<string \| null>` | GET | index番目のキーを取得する |
| `clear()` | `Promise<{v, items}>` | DELETE | 現在のオリジンのデータを全削除する |
| `deleteDomainData()` | `Promise<{v, items}>` | DELETE | `clear()` と同じ |
| `sync()` | `Promise<{v, items}>` | GET | サーバーから全データを取得し、キャッシュを更新する |
| `readCache()` | `{v, items}` | なし | キャッシュを同期的に返す |
| `accountInfo()` | `Promise<object>` | GET | アカウント情報を取得する |
| `getAccountInfo()` | `Promise<object>` | GET | `accountInfo()` と同じ |
| `usage()` | `Promise<object>` | GET | 容量情報を取得する |
| `getUsage()` | `Promise<object>` | GET | `usage()` と同じ |
| `constants` | object | なし | 設定値（読み取り専用） |

---

## login()

ログイン画面をポップアップで開き、認証結果を受け取ります。

```js
const result = await OF8.login();
console.log(result.account.name);
```

**戻り値**

```json
{
  "accessToken": "v1.xxxx.....",
  "signature": "....",
  "account": { "id": "taro", "name": "太郎", "icon": null, "iconMimeType": null }
}
```

**動作**

1. ランダムな `state` を生成し、`sessionStorage` に保存する。
2. `about:blank` のウィンドウを開き、そこへログイン画面（`https://search3958.github.io/support/accounts/account-login.html?origin=...&state=...`）へ遷移させる。
3. ログイン画面からの `postMessage`（`type: "OF8_AUTH_RESULT"`, `version: 2`）を待つ。送信元のオリジンとウィンドウが一致し、`state` も一致する場合のみ受け付ける。
4. Cookie（トークン、署名）とデータアクセスキーを保存する。
5. ポップアップを閉じて結果を返す。

**エラー**

| 状況 | メッセージ（例） |
|---|---|
| ポップアップがブロックされた | `Login popup was blocked by the browser.` |
| ユーザーがポップアップを閉じた | `ログイン画面が閉じられました。` |
| 5分間応答がない | `ログインウィンドウがタイムアウトしました。` |
| Cookieに保存できなかった | `認証情報をこのサービスに保存できませんでした。Cookie設定を確認してください。` |

## logout()

サーバー側のトークンを失効させ、ローカルのCookie・鍵・キャッシュを削除します。

```js
await OF8.logout();
```

- Cookieがない場合はサーバーへの通信を行わず、ローカル削除のみ行います。
- サーバー通信に失敗しても、ローカルの削除は行われます。

---

## isLoggedIn()

```js
if (await OF8.isLoggedIn()) {
  // ログイン済み
}
```

- Cookieがない場合は即座に `false`。
- Cookieがある場合は `POST /v1/auth/introspect` で検証します。失敗時は `false`。

---

## getItem(key)

```js
const value = await OF8.getItem("settings"); // 存在しない場合は null
```

- 引数は `String(key)` に変換されます。
- 呼び出すたびにサーバーから全データを取得します。

---

## setItem(key, value)

```js
await OF8.setItem("settings", JSON.stringify({ theme: "dark" }));
```

- `value` は `String(value)` に変換されます。
- 戻り値は保存後の全データ `{ v: 1, items: {...} }` です。
- 内部で同期 → 更新 → 保存の順に行われます。連続して呼ぶ場合は直列化してください（「詳しいデータの扱い方」参照）。

---

## removeItem(key)

```js
await OF8.removeItem("settings");
```

- 存在しないキーを指定してもエラーにはなりません。

---

## keys() / length() / key(index)

```js
const all = await OF8.keys();      // ["settings", "memo"]
const count = await OF8.length();  // 2
const first = await OF8.key(0);    // "settings" または null
```

- いずれもサーバーから全データを取得してから計算します。

---

## clear() / deleteDomainData()

```js
await OF8.clear();
```

- 現在のオリジンのデータだけを削除します。他のアプリのデータは残ります。
- `deleteDomainData()` は `clear()` の別名です。

> 取り消しはできません。実行前にユーザーへ確認を取ってください。

---

## sync()

```js
const data = await OF8.sync();
```

- サーバーの最新データを取得し、キャッシュを上書きします。
- 別端末で更新された内容を取り込みたいときに使います。

---

## readCache()

```js
const data = OF8.readCache();
```

- ネットワークにアクセスしません。
- キャッシュがない場合は `{ v: 1, items: {} }` を返します。
- JSON が壊れている場合も空データを返し、コンソールにエラーを出力します。

---

## accountInfo() / getAccountInfo()

```js
const info = await OF8.accountInfo();
console.log(info.account.name, info.permissions);
```

**戻り値の主な項目**

| 項目 | 内容 |
|---|---|
| `account.id` | ユーザーID |
| `account.name` | 表示名 |
| `account.icon` | アイコンのBase64（なければ `null`） |
| `account.iconMimeType` | アイコンの MIME タイプ |
| `permissions` | `{ read: boolean, write: boolean }` |

---

## usage() / getUsage()

```js
const { usage } = await OF8.usage();
console.log(usage.dataChars, usage.maxDataChars);
```

**主な項目**

| 項目 | 内容 |
|---|---|
| `version` | データ形式のバージョン |
| `dataChars` | 全体の文字数 |
| `dataBytes` | 全体のバイト数 |
| `iconBytes` | アイコンのバイト数 |
| `accountInfoBytes` | アカウント情報のバイト数 |
| `tokenBytes` | トークン情報のバイト数 |
| `accountStorageBytes` | 合計バイト数 |
| `maxDataChars` | 上限文字数 |
| `domains` | オリジンごとの `domain` / `encryptedChars` / `encryptedBytes` |

---

## constants

読み取り専用の設定値です。

```js
OF8.constants.apiBase;            // API のベースURL
OF8.constants.popupUrl;           // ログイン画面のURL
OF8.constants.cookieToken;        // "__Host-of8_access_token"
OF8.constants.cookieSignature;    // "__Host-of8_access_signature"
OF8.constants.storageKey;         // データアクセスキーの保存キー
OF8.constants.storageDataKey;     // キャッシュの保存キーの接頭辞
OF8.constants.popupWidth;         // 460
OF8.constants.popupHeight;        // 720
```

## エラーの取り扱い（共通）

APIからのエラーは次の形式で届き、クライアントが `Error` に変換します。

```json
{ "ok": false, "error": { "code": "token_expired", "message": "..." }, "requestId": "..." }
```

`error.message` をそのままユーザーに見せることができます。
代表的な `code` は「トラブルシューティング」を参照してください。

## 呼び出し例：エラー処理をまとめる

```js
async function safeCall(fn) {
  try {
    return { ok: true, value: await fn() };
  } catch (error) {
    console.error(error);
    return { ok: false, message: error.message };
  }
}

const r = await safeCall(() => OF8.getItem("memo"));
```
